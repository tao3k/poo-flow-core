#+title: POO Flow Foundation

* Purpose

This repository owns the minimal POO-native contracts and observability
modules shared by gerbil-parser and full POO Flow. It is a separate Gerbil
package to keep the dependency graph acyclic:

#+begin_example
gerbil-poo + ASP Scheme → Foundation → gerbil-parser → POO Flow
#+end_example

* Module ownership

The Gerbil module prefix is =poo-flow-foundation=. Consumers import its
contracts directly rather than attributing them to the full POO Flow package.
=module-system/types.ss=, =object-family/=, =composition/lineage.ss=, and
=observability/= live here.  Lineage analysis is a pure shared kernel; POO
Flow retains composition proof facts and module admission. Full POO Flow must
not compile another copy of these module IDs.

The =observability/testing-case= module owns the reusable POO Case profile and
its native =std/test= adapter. Downstream packages extend =memory-policy= and
=max-duration-milliseconds= slots instead of defining another Case wrapper.

The Foundation Git revision is pinned by both gerbil-parser and POO Flow.
POO Flow also carries this repository as a Git submodule for source inspection
and coordinated development; =gxpkg= installs the package from its own URL.

* Build and test

With Gerbil v0.19 and dependencies installed in an isolated =GERBIL_PATH=:

#+begin_src sh
gerbil deps --install
gerbil build
just test
#+end_src
